# Venture Charter — Niche Micro-SaaS

## What this venture is

A small software product that solves one painful, recurring workflow for one specific
industry, sold as a monthly subscription. The first version is deliberately a
*concierge* service — the workflow done manually for paying customers — so the pain,
the price, and the spec are proven before any software is built.

## Why the platform is doing it

Ranked #3 on the opportunity scoreboard (77/100): the best margins and stickiest
recurring revenue on the board, and near-total automation once stable (rung 4 with
support as the main human load). It is the platform's long-game compounder — slower
than the other two chartered ventures, worth more if it lands.

## Owner and stage

- **Owner:** Troy
- **Current stage:** 1 — Validate
- **Structure:** Internal line of business

## Success looks like

- 30 discovery conversations in the chosen niche within 45 days.
- 5 customers paying monthly for the concierge (manual) version before any code is
  written.
- A written spec derived from concierge delivery, not from imagination.

## Kill / rethink criteria

- After 30 discovery conversations, no single workflow pain shows up repeatedly with
  willingness to pay monthly → change niche or park the venture.
- Concierge customers churn within the first two months → the pain is real but not
  recurring; don't build software on it.
- **Hard rule:** no software build before 5 paying concierge customers. Building first
  is how this venture-type dies.
